Libraries needed:
torch 
torchvision 
torchaudio 
matplotlib 
numpy
tqdm 
ipywidgets
soundfile

for CUDA enabled devices. Check with pytorch website for specific version. https://pytorch.org/get-started/locally/

PASTE:
pip install torch torchvision torchaudio --index-url https://download.pytorch.org/whl/cu128
pip install matplotlib numpy tqdm ipywidgets==7.7.2 soundfile
